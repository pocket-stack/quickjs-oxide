02 / What you are running

        

          
No browser-native shortcut.

          

            

              Your source is sent to a dedicated worker and evaluated by the
              quickjs-oxide Rust engine. The playground does not pass it to the
              page’s JavaScript evaluator.
            

            

              Feature parity with pinned QuickJS remains the destination. Some
              programs will fail today; those failures are useful, visible
              checkpoints—not hidden fallbacks.
            

            

              This editor currently exposes the Script goal. Static modules
              and core import.meta run in the Rust engine, but the
              browser UI does not yet expose its module-loader API.
            

            

              The engine version, compatibility target, host policy, and build
              commit shown above are reported by the loaded WASM package.
